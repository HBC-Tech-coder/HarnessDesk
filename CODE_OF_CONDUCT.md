# Code of Conduct / 行为准则

We are committed to a respectful, harassment-free project space.

Expected behavior:

- discuss evidence and impact, not personal attributes;
- welcome different levels of experience;
- protect private data and security reports;
- correct inaccurate release claims promptly;
- respect upstream maintainers, users, and trademark owners.

Unacceptable behavior includes harassment, threats, discriminatory language, doxxing, publishing private logs or credentials, impersonation, and knowingly misleading users about official affiliation or release safety.

For ordinary moderation concerns, open a minimal issue without private details. If the concern includes a security or privacy risk, use GitHub Private Vulnerability Reporting. Maintainers may edit, hide, lock, or remove content and may restrict participation when needed.

我们致力于维护尊重、无骚扰的协作空间。请围绕证据讨论，保护隐私与安全报告，尊重上游维护者、用户和商标权利人。骚扰、威胁、歧视、开盒、泄露凭据、冒充官方或故意误导发布安全状态均不可接受。
