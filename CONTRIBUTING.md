# Contributing / 参与贡献

This public repository currently contains documentation and release metadata only. Product source for the Legacy Preview is not published here.

You may:

- report a documentation error;
- report a reproducible installer or security issue using redacted evidence;
- propose clearer compatibility, license, SmartScreen, or verification wording.

Do not submit:

- product source copied from private or unreviewed worktrees;
- installers, archives, model files, Cubism runtime files, user data, logs with private content, or secrets;
- claims that planned, local-only, or failed functionality is production-ready;
- branding that presents HarnessDesk as an official DeepSeek product.

Documentation pull requests should be small, factual, bilingual where practical, and should preserve the Legacy Preview failure matrix.

当前公开仓只包含说明与发布元数据。欢迎纠正文档和提交脱敏、可复现的问题；禁止提交未验收源码、安装包、模型/Cubism 文件、用户数据、秘密值或误导性官方背书。
