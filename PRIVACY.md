# Privacy notice / 隐私说明

The Legacy Preview is a local desktop wrapper. During testing it created local application data under:

    %APPDATA%\deepseek-harness-windows-desktop

The packaged update URL is empty, so the updater is disabled in this build. No claim is made that every other dependency is network-silent. When a user configures and invokes a model provider, prompts, files, tool output, or metadata may be sent to that provider under its own terms.

The Legacy Preview does not provide verified HarnessDesk unified accounts, SMS login, hosted quota, hosted proxy, payments, or production BYOK storage. Do not place secrets or personal data in public issues. Review logs before sharing and redact local paths, prompts, provider identifiers, and tokens.
