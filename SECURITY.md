# Security Policy / 安全策略

## Supported versions / 支持版本

HarnessDesk currently has no supported production release.

The Legacy Preview 0.1.0-rc.6 is archived for testing and provenance only. It is unsigned, failed two independent cold starts, and does not receive security updates through a live feed.

HarnessDesk 当前没有受支持的生产版本。Legacy Preview 0.1.0-rc.6 仅用于测试与来源留档；它未签名、两次独立冷启动失败，也没有在线安全更新通道。

## Report privately / 私密报告

Use GitHub Private Vulnerability Reporting:

https://github.com/HBC-Tech-coder/HarnessDesk/security/advisories/new

Do not include passwords, API keys, tokens, cookies, one-time codes, private keys, customer data, or full private logs. Provide the release tag, exact asset SHA-256, Windows version, minimal reproduction steps, and a redacted impact description.

请勿提交密码、API Key、Token、Cookie、验证码、私钥、客户数据或完整隐私日志。请提供 Release tag、资产 SHA-256、Windows 版本、最小复现步骤和脱敏影响说明。

## Scope / 范围

Security reports about HarnessDesk packaging, updater behavior, local privilege boundaries, and release integrity belong here. Issues reproducible in the unmodified upstream project should also be reported to the upstream maintainers without implying that HarnessDesk is official.
